# Workout Tracker

Static mobile workout tracker.

## Local development

This app is a single static `index.html` file. To preview it with Vercel's local runtime:

```sh
npm run dev
```

To run a quick syntax check for the inline app script:

```sh
npm run check
```

## Deploy on Vercel

Upload this folder to a GitHub repository, then import the repository in Vercel.

Framework preset: Other
Build command: leave blank
Output directory: leave blank
Install command: leave blank
